This is a simple battle royale game built using C++ and OpenGL. The game features a large map where players can explore, gather resources, and fight against each other until only one player remains. 
The game includes various weapons, health packs, and other items that players can use to gain an advantage over their opponents. The map also shrinks over time, forcing players into closer proximity and increasing the intensity of the battles.
To play the game, simply run the executable file and follow the on-screen instructions. Use the WASD keys to move, the mouse to aim and shoot, and the spacebar to jump.
The game also includes a simple user interface that displays the player's health, ammo, and other important information. Players can also customize their character's appearance and loadout before starting a match.
